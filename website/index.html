  1. 01

    下载并安装

    下载 Windows 安装包，双击后按提示完成安装。升级前，请先在托盘菜单中退出旧版。

  2. 02

    确认「已连接」

    打开助手，登录英雄联盟客户端。若迟迟未连接，尝试以管理员身份重新打开助手。

    客户端更新或维护期间，可稍后点击「重新连接」。

  3. 03

    选好规则，开始一局

    在设置里选好你们约定的规则，保持助手运行。点击窗口 × 会收进托盘；右键托盘图标选择「退出」才会结束运行。

常见问题

新版怎么升级？

先右键系统托盘中的助手图标，选择「退出」，再运行官网下载的新安装包。当前版本通过官网手动升级；已有算分规则设置会继续保留。

会修改游戏数据吗？

助手读取本机客户端的对局数据，不提供修改客户端或代打操作。项目为独立开源工具，与 Riot Games、腾讯没有官方关联；请以游戏官方的使用规则为准。

支持哪些模式？

主要面向英雄联盟大乱斗。其他 LOL 模式取决于客户端提供的数据和分组方式，结算时请核对参与玩家。

历史对局的分队为什么可能不准？

楼层顺序只在选英雄阶段可获取。助手未及时启动或未成功连接时，只能根据对局记录推测顺序。请在选英雄前启动，并确认显示「已连接」。

能设置红包金额吗？

目前只计算结果并显示最低分玩家或队伍，金额由朋友之间自行约定。软件不处理收款、付款或转账。

Mac 或手机能用吗？

当前提供 Windows 10 / 11 的 64 位安装包，手机和 macOS 暂不支持。

下载慢或失败怎么办？

主按钮使用官网直连。若当前网络不稳定，可以重新下载，或使用上方 GitHub 备用入口。文件校验页提供 SHA-256，方便核对安装包完整性。
